# Домашнее задание к работе №4

## #1. Алгоритм

1. Начало
2. Ввод данных: A — номер рабочего места Анны (вводит пользователь), B — номер рабочего места Бориса (вводит пользователь).
3. Вычислить результат: кофе готовится, если ровно один из программистов имеет четный номер рабочего места.
   * Условие: (A четное И B нечетное) ИЛИ (A нечетное И B четное).
   * В языке С это реализуется через оператор исключающего ИЛИ (XOR) или логическое неравенство: `result = ((A % 2 == 0) ^ (B % 2 == 0));`
4. Вывести результат (1 — кофе готовится, 0 — кофе не готовится).
5. Конец

### Блок-схема

graph TD
    Start((Начало)) --> InputA[/Ввод A/]
    InputA --> InputB[/Ввод B/]
    InputB --> Condition{A%2 != B%2?}

    Condition -- Да --> SetResult1[result = 1]
    Condition -- Нет --> SetResult0[result = 0]

    SetResult1 --> Output[/Вывод result/]
    SetResult0 --> Output

    Output --> End((Конец))

#2. Реализация программы
#include <stdio.h>
#include <locale.h>
#define _CRT_SECURE_NO_WARNINGS

void main() {
    setlocale(LC_ALL, "RUS");
    int A, B, result;

    puts("Введите номер рабочего места Анны (A):");
    scanf("%d", &A);

    puts("Введите номер рабочего места Бориса (B):");
    scanf("%d", &B);

    // Условие "ровно один четный" реализуется через XOR (исключающее ИЛИ)
    // Если номера разной четности, result будет равен 1
    result = ((A % 2 == 0) ^ (B % 2 == 0));

    printf("Результат (1 - кофе готовится, 0 - кофе не готовится): %d", result);
}
